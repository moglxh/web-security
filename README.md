# Web Security / Bug bounty

This repository contains notes, lab work, research, and practical exercises related to web application security.

The material focuses on understanding how modern web applications function, how vulnerabilities arise, and how they can be identified, reproduced, and studied in controlled environments.

Most content is based on hands-on experimentation, HTTP analysis, and security testing labs.

## Areas Covered

* HTTP Fundamentals
* Authentication
* Session Management
* Access Control
* SQL Injection
* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* Server-Side Request Forgery (SSRF)
* File Upload Vulnerabilities
* Path Traversal
* Command Injection
* Information Disclosure
* API Security
* Business Logic Vulnerabilities

## Purpose

The goal of this repository is to document practical web security research and application testing techniques while building a deeper understanding of how web technologies operate.

Rather than collecting challenge completions, the emphasis is placed on documenting observations, attack paths, root causes, and remediation concepts.
